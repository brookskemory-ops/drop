# Brand Identity — STRYV

Locked-in identity and the production steps to take the current designs from AI mockups to
print-ready assets. Name chosen: **STRYV** (from "strive").

---

## The identity so far

| Element | Decision |
|---------|----------|
| **Name** | STRYV |
| **Sub-line** | STRYV ATHLETIC CLUB (community/gym-to-street positioning) |
| **Aesthetic** | Bold typographic × minimalist (clean chest mark + bold statement back) |
| **Colors** | Black + **red accent** (the "V"), on white/cream. Red is now the brand color. |
| **Front** | Minimalist STRYV wordmark, small chest placement |
| **Back** | Bold stacked "STRYV ATHLETIC CLUB" + tagline, red V accent |

The two pieces already work as a system — the red V links front to back. Keep that consistent.

---

## Production fixes before printing (in priority order)

1. **Make light/reversed versions for dark garments.** Both current designs are black-on-light,
   which is invisible on black/charcoal tees — and dark colorways sell hard in this niche.
   Produce a **white (+ red) version** of both the wordmark and the back graphic. *(Highest priority.)*
2. **Vectorize the typography.** Current files are AI rasters. Rebuild the wordmark as **actual
   vector text** (Kittl or Illustrator) so it's razor-sharp at any size and identical across tee,
   hoodie, and woven neck label. AI type can have subtly uneven letterforms up close.
3. **Lock the exact colors.** Pick precise hex/Pantone for the red and black so every print,
   label, and web asset matches. (Establish a mini brand kit — see below.)
4. **Export print-ready:** transparent PNG, **300 DPI**; back graphic ~**3600–4200px** wide
   (~12–14"); front chest mark small (~3–4").

## Tagline options (build equity off the name)

"No Excuses · No Limits" is clean but generic. Since the name means *strive*, lean into it:

- ⭐ **KEEP STRYVING** — turns the name into a rallying cry (community-friendly)
- ⭐ **ALWAYS STRYVING**
- **STRIVE FOR MORE**
- **EARN IT**
- **BUILT NOT BOUGHT**
- **OUTWORK YESTERDAY**
- **NEVER SETTLE**

A name-based tagline ("Keep Stryving") reinforces the brand every time it's read — worth it.

## Mini brand kit (lock these so everything matches)

- **Primary:** Black / off-white
- **Accent:** the red (pick an exact hex, e.g. a punchy true red)
- **Type:** one heavy condensed athletic sans for display (the wordmark), one clean sans for body
- **Logo lock-ups:** (a) STRYV wordmark, (b) STRYV ATHLETIC CLUB stacked, (c) small icon/monogram
  (a standalone red "V" could become a neat pocket/label mark)
