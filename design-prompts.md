# AI Design Prompt Pack — Front & Back (Men's Gym Basics)

Paste-ready prompts for your first drop. Four distinct aesthetics, each with a **front (chest
mark)** and **back (statement graphic)** prompt. Swap `[BRAND]` for your brand name. Built to the
print-ready rules in [`sourcing-and-ai-design.md`](./sourcing-and-ai-design.md).

## How to use this pack

1. Pick **one** aesthetic below (don't mix — a drop should feel cohesive).
2. **Front** = subtle (small chest mark). **Back** = the big statement. Generate both.
3. Run graphic prompts in **Midjourney**; run **text/wordmark** prompts in **Ideogram** (its
   text is accurate — Midjourney garbles letters).
4. Take the output into **Kittl**: remove background → upscale to **300 DPI transparent PNG**
   (or vectorize bold/flat designs).

### Prompt rules baked into these (why they're written this way)
- **"isolated on plain white background, centered"** → makes background removal clean.
- **"limited 2–3 color palette"** → prints cheaper and sharper on DTG/DTF; looks more premium.
- **"flat / bold linework / high contrast"** → holds up at print size; avoids muddy gradients.
- **`--ar 1:1`** for chest marks, **`--ar 4:5`** for back graphics (portrait print area).
- **`--style raw --v 7`** → more literal, less "AI-glossy" output you can control.

## After you generate — the checklist

- [ ] Background removed, saved as **transparent PNG, 300 DPI**.
- [ ] Back graphic file built ~**3600–4200px wide** (~12–14" at 300 DPI); front mark small (~3–4").
- [ ] Colors reduced to a **tight palette** (2–3) — cleaner print, lower cost.
- [ ] Text is **crisp and correctly spelled** (regenerate in Ideogram or re-set the type in Kittl).
- [ ] **No** copied logos, brands, characters, or real people (takedown/legal risk).
- [ ] Ordered a **physical sample** and wear-tested it before launching.

## Prompt-tuning tips
- If output is too "AI-glossy," add: `flat, 2D, screen-print, no gradients, no 3D`.
- If it adds a shirt/mockup you don't want, add: `no shirt, no mockup, just the graphic`.
- To lock a color story, name the exact colors (e.g. `cream and faded navy only`).
- Generate **4–6 variations** of each and pick; iterate the winner rather than starting over.
